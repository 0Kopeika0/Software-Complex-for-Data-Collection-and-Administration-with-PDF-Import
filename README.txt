Название: Программный комплекс для сбора и администрирования данных с импортом из PDF / Software Complex for Data Collection and Administration with PDF Import

Стек: Python, SQL (SQLite), JavaScript, HTML, CSS, FastAPI

Что делает: Автономный клиент-серверный веб-комплекс для сбора и администрирования данных с импортом из PDF; разграничение прав, JWT/bcrypt/HTTPS, кроссплатформенность (Windows/Linux), доступ через браузер.


Модули backend (Python/FastAPI):
    main.py — главный модуль: маршруты API, обработка HTTP-запросов, запуск Uvicorn, интеграция подсистем.
    pdfFile.py — OCR документов: загрузка PDF, конвертация страниц в изображения (pdf2image), извлечение текста (EasyOCR), нечёткое сравнение строк по расстоянию Левенштейна.
    WriteFile.py — запись в SQLite: организации, заявки, основная информация, роли, должностные лица, персональные данные; проверка дубликатов.
    RemoveBD.py — удаление данных: поиск связанных записей, каскадное удаление с сохранением целостности.
    ReqvestFile.py — извлечение данных из БД: формирование массивов для таблиц интерфейса.
    WriteExcel.py — экспорт в Excel: парсинг HTML-таблицы, формирование отчёта, запись .xlsx через openpyxl.
    Passwords.py — управление паролями: хэширование (bcrypt), добавление/удаление/изменение учётных записей администраторов.
    Name.py — валидация и форматирование ФИО: проверка ввода, преобразование в структурированный формат.

Frontend (HTML/CSS/JS):
    admin.html — интерфейс администратора: таблица заявок, модальные окна добавления/изменения/удаления, экспорт в Excel, управление ролями.
    user.html — интерфейс пользователя: форма заявки, кнопка OCR-распознавания, модальные окна ролей и загрузки PDF.
    superadmin.html — интерфейс суперадминистратора: управление учётными записями администраторов, смена логина и пароля.
    admin.css — стили админ-интерфейса: таблицы, модальные окна, кнопки, затемнение фона, адаптивность.
    user.css — стили пользовательского интерфейса: формы ввода, таблицы, модальные окна, индикаторы загрузки.

Скрипты запуска:
    start_windows.bat — запуск в Windows: активация venv, старт Uvicorn.
    start_linux.sh — запуск в Linux: активация venv, старт Uvicorn.
